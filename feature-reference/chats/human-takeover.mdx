---
title: "Human takeover (pausing automation)"
description: "When and how to pause a workflow to take over a chat manually"
---

## What it does

If a contact has an automated workflow running, you can **pause** it to take the conversation over yourself — for example, if the automation isn't handling the situation well, or a customer needs a human. Pausing freezes that workflow entirely: it won't send anything or react to the contact's replies while paused.

You can pause for a set number of minutes, or indefinitely until you manually unpause.

## When to use it

Reach for human takeover whenever an automated conversation needs a person — an edge case the workflow doesn't handle, an upset customer, a complex question. It's scoped to one conversation at a time; it doesn't affect other contacts running the same workflow.

## How to configure it

From an open conversation in Chats, pause the automation for that contact and choose a duration (or indefinite). Unpause the same way, or let it expire on its own if you set a time limit. When a paused workflow resumes, anything it was waiting on (a timer, a reply prompt) picks back up from where it left off.
