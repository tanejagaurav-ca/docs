## What it does

The Workflows gallery offers ready-made **recipes** — pre-built workflows for common needs (an FAQ auto-reply, appointment scheduling, CRM lookups, support ticket updates, document collection, and more). Each tile previews a sample conversation so you can see what it does before adopting it.

Some recipes need a connected integration to work (for example, a CRM lookup recipe needs that CRM connected). The gallery shows each recipe's requirements and whether they're already met.

## When to use it

Start from a recipe whenever one is close to what you need — it's faster than building from scratch, and you can still customize it afterward like any other workflow.

## How to configure it

Browse the gallery, open a recipe's detail view to see what it does and what it requires, connect any missing integrations directly from there, then adopt it to create your own editable copy.
