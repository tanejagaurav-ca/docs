---
title: "Building your first automation"
description: "A step-by-step tutorial: an FAQ auto-reply"
---

<Note>
  Every account starts with a "Welcome auto-reply" workflow, created automatically during onboarding — see [Signup and onboarding](/getting-started/signup-and-onboarding). This tutorial walks through building one yourself.
</Note>

<Steps>
  <Step title="Create a new workflow">
    From the Workflows gallery, start blank or adopt a recipe close to what you want.
  </Step>
  <Step title="Set the trigger">
    Choose **Message received** so the workflow answers inbound WhatsApp messages. Optionally add a filter (for example, only match certain keywords).
  </Step>
  <Step title="Add a reply">
    Add a "send message" step with your answer. For a simple FAQ reply, this can be the whole workflow.
  </Step>
  <Step title="Test it">
    Use the Test button to run the workflow manually (a dry run — no real message is sent), and check the run history to see each step's outcome.
  </Step>
  <Step title="Enable it">
    Switch the workflow on. Remember: only one message-triggered workflow can be active at a time, so enabling this one drafts any other.
  </Step>
</Steps>
