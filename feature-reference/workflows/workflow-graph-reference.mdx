## Node types

A workflow graph is made of nodes connected by edges. Common node types include: send a message, wait for a reply, a conditional branch, set a variable, call a connected integration (`rest_api`), schedule a follow-up workflow, file a document, and calendar actions (book/cancel/reschedule an appointment).

## Conditions

Branches evaluate a condition group against the current context — for example, matching the text of a customer's reply, or a value a previous step set.

## Context / variables

Each run carries an accumulating **context**: what triggered it, the contact's details, the customer's replies, and anything a step explicitly sets. Later steps can reference earlier values (for example, to personalize a message with something the customer said two steps ago).
