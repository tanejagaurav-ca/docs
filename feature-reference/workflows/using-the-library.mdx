## What it does

The Library is a browsable catalogue of starting points for **message templates** and **WhatsApp Flows** — both app-curated examples and anything your own team has saved. Adopting a Library item fills in its placeholders and gives you an editable draft to refine.

## When to use it

Use the Library when you're authoring a new message template or Flow and don't want to start from a blank page.

## How to configure it

Open the Library, pick an item, and adopt it — it becomes a draft you can edit like anything you'd authored yourself. Authoring from the Library is restricted to owners and admins, same as Templates.
