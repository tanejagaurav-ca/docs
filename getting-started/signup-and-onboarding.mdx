## Signing up

There are two ways to sign up and create an Epitomos account:

<Tabs>
  <Tab title="Google">
    Sign up using your Google account.
  </Tab>
  <Tab title="Work email">
    Enter your work email address. Epitomos sends a link to that email for you to set up your password for the first time.
  </Tab>
</Tabs>

## Onboarding wizard

Once you've signed up, logging in for the first time presents you with an onboarding wizard. Completing it is **mandatory** — you can't use Epitomos until it's done.

The wizard asks a few basic questions about your business:

| Field | Notes |
| --- | --- |
| Business name | |
| Industry | The industry your business belongs to |
| Phone number | The number you wish to onboard to WhatsApp as your business number, or one you've already onboarded to WhatsApp |
| Company website | |
| Address | |
| Days and hours of operation | |
| Timezone | |

<Note>
  All of these can be changed later — see your account's Settings section.
</Note>

## Demo workflow

At the very end of the onboarding wizard — right before the guided tour — Epitomos automatically creates a demo workflow customized from the company information you provided in the earlier steps. This demo workflow is deployed and live immediately, running on Epitomos's sandbox WhatsApp number.

You're shown a QR code and a **Chat on WhatsApp** button so you can try the demo workflow right away, without needing your own WhatsApp Business number connected yet.

## Guided tour

Once onboarding is complete, a brief in-app guided tour walks you through the features Epitomos offers. The tour can be skipped.

The tour's first step highlights an **onboard** button in a banner at the top of the dashboard. This launches the same [Meta embedded signup](/getting-started/meta-embedded-signup) process described in the next section.

Completing the tour (or skipping it) finishes signup and onboarding — you're ready to start using Epitomos.
